Commands Reference

A complete reference for all Bread Discord bot commands.

Authentication

/login Authenticate your Epic Games account.
/logout Disconnect your Epic Games account.

Account

/account change-displayname Change the display name of your Epic Games account.

Arguments

displayname required

The Display Name you want to change to.

/account information View your Epic Account Information (Sensitive Information)
/account lookup Look up a Fortnite account.

Arguments

accountid required

The Epic Games account ID to look up.

/account permissions View your Account Permissions for the logged in client (Android Client)
/account ranked View your fortnite ranked stats, or someone else.

Arguments

displayname optional

Enter an Epic Display Name to display another user's stats. (You should be able to search anyone's stats regardless of their privacy settings)

/account summary View your fortnite account summary. (e.g Account Level, Season Wins, Season Crowns)

Game

/playtime View Fortnite playtime across platforms.

Interactive Options

Xbox

Prompts optional login options through Xbox if an epic account isn't available to the user.

Playstation

Prompts optional login options through Playstation if an epic account isn't available to the user.

/xp View your XP progress for all gamemodes.
/ranked-modes Shows the current active ranked tracks in Fortnite.
/island Search for a Fortnite island by it's code.

Arguments

code required

The island code you want to check.

/pendingrewards Processes pending rewards for your linked fortnite account. (Like what fortnite does on login if you've ever seen that message)
/requestaccess Request access to the Fortnite/Epic APIs if you haven't accepted the EULA/don't have 'PLAY' Action.
/session Displays your current fortnite session details.

Ban

/checkban account Check if your fortnite account is banned.
/checkban social Check if your fortnite account is social banned.

Redeem

/code info View information about a redemption code.
/code redeem Redeem a code on your fortnite account.

Creator Code

/creator auto-renew Enable or update automatic creator support.

Arguments

code required

The Support-A-Creator Code you want to auto renew.

/creator code-info Check a Support-A-Creator Code info.

Arguments

code required

The Support-A-Creator Code you want to check.

/creator profile View a Fortnite Creator's profile.

Arguments

code required

The Support-A-Creator Code you want to check.

/creator renew-disable Disable automatic Support-A-Creator Code.

Locker

/locker view View locker categories.
/locker exclusives Show exclusive cosmetics.
/estimatedvalue Estimate locker value.
/emote pages Shows how many locker pages your emotes take up (8 per page)

Friends

/friends acceptall Accept all incoming friend requests on your Epic Games account.
/friends list List all friends on your Epic Games account.
/friends removeall Remove all friends.
/friends search Search for an Epic Games user in your friends list.

Arguments

username required

The epic display name to check.

Gifting

/gifts sent View sent gifts.
/gifts received View received gifts.

V-Bucks

/vbucks balance Check V-Bucks balance.
/vbucks totalpurchased View your total V-Bucks purchased.

Information

/status Fortnite downtime and uptime status.
/notifications Manage server notifications. (Notifications for things like epic service updates, new jam tracks, shop tabs, ect)
/packoffer Fetch fortnite pack offer details. [Useful if you know what you're doing]

Arguments

appstoreid required

The Appstore ID of the pack to check.

/recentjam Displays the most recently added Jam Track.
/reloadpeakccu Shows a graph of the peak CCU for Reload over time.
/searchartist Search for all Jam Tracks by an artist.

Arguments

artist required

The name of the artist to check.

/searchjam Search for a Jam Track by name or artist.

Arguments

query required

What Jam Track to search for.

/shop Send the current Fortnite Item Shop.
/steamprofile Search someone's Steam profile by URL Name or SteamID64. (This is non fortnite related)

Arguments

input required

Steam ID or URL.
